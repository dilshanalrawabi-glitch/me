# Project images – paste your screenshots here

**Folder:** `public/projects/`

Paste your project screenshots into this folder. The Projects section will use them automatically if you use these **exact file names**:

| Project   | File names that work      |
|-----------|----------------------------|
| **POS**   | `pos.jpg` or `pos.png`     |
| **Bochemar** | `bochemar.jpg` or `bochemar.png` |
| **Iinve** | `iinve.jpg` or `iinve.png` |

- You can use either **.jpg** or **.png** – the site tries both.
- Replace the existing placeholder files with your own if you want.
- After pasting, refresh the page to see your images on the Projects section.
